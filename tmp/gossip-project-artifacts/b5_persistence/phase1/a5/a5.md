A5 - Persistence conformance test suite (backend-agnostic)

Goal

A set of tests every backend must pass.

Tests

Done-ledger:

Idempotent upsert on same key

Scanned dominates Failed under out-of-order writes

Findings:

Idempotent insert on same IDs under retry

Referential integrity rules (occurrence references finding, observation references occurrence)

Redaction:

Debug for sensitive types never prints raw bytes

Acceptance

One fn run_conformance(impl DoneLedger, impl FindingsSink) style harness that real backends can reuse.
