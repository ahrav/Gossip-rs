# AVX-512 Intrinsics Reference for Rust

Reference for `core::arch::x86_64` AVX-512 intrinsics. Covers sub-extensions,
mask registers, key intrinsics, frequency throttling, and runtime detection.

## AVX-512 Family Overview

AVX-512 is a family of sub-extensions. F is always the foundation. Check each
extension independently at runtime.

| Extension | What It Adds | `target_feature` |
|-----------|-------------|-------------------|
| **F** | 512-bit int/FP, 32 ZMM regs, 8 opmask regs (k0-k7), merge/zero masking | `avx512f` |
| **CD** | Conflict detection (`vpconflictd/q`), leading zero count | `avx512cd` |
| **BW** | Byte/word (8/16-bit) ops in 512-bit vectors; `__mmask32`/`__mmask64` | `avx512bw` |
| **DQ** | Dword/qword multiply (`vpmullq`), `__mmask8` for 64-bit element ops | `avx512dq` |
| **VL** | AVX-512 features (masking, new ops) at 128/256-bit widths | `avx512vl` |
| **IFMA** | 52-bit integer FMA for big-integer / crypto | `avx512ifma` |
| **VBMI** | Full cross-lane byte permute (`vpermb`, `vpermi2b`) | `avx512vbmi` |
| **VBMI2** | Byte/word compress/expand, concatenate-and-shift | `avx512vbmi2` |
| **BITALG** | Byte/word popcount, bit shuffle to mask | `avx512bitalg` |
| **VNNI** | Int8/int16 dot-product accumulate for inference | `avx512vnni` |

**CPU bundles**: Skylake-X = F+CD+BW+DQ+VL. Ice Lake adds IFMA+VBMI+VBMI2+
BITALG+VNNI+VPOPCNTDQ. AMD Zen 4 matches Ice Lake plus BF16. Alder Lake /
Raptor Lake have AVX-512 fused off (hybrid E-cores lack support).

## Mask Registers

Dedicated opmask registers (`k0`-`k7`) for per-element predication. Mask width
matches element count in the vector.

| Rust Type | Width | Used With |
|-----------|-------|-----------|
| `__mmask8` | 8 bits | 512-bit on 64-bit elements (8 lanes) |
| `__mmask16` | 16 bits | 512-bit on 32-bit elements (16 lanes) |
| `__mmask32` | 32 bits | 512-bit on 16-bit elements (32 lanes) |
| `__mmask64` | 64 bits | 512-bit on 8-bit elements (64 lanes) |

**Merge-masking** (`_mm512_mask_*`): inactive lanes retain the `src` operand.
**Zero-masking** (`_mm512_maskz_*`): inactive lanes become zero.

```rust
let merged = _mm512_mask_add_epi32(src, mask, a, b);  // inactive = src[i]
let zeroed = _mm512_maskz_add_epi32(mask, a, b);      // inactive = 0
```

**Mask arithmetic** (runs on dedicated k-register units, not vector ALU):

```rust
let and:    __mmask16 = _kand_mask16(m1, m2);    // AND
let or:     __mmask16 = _kor_mask16(m1, m2);     // OR
let not:    __mmask16 = _knot_mask16(m1);         // NOT
let andnot: __mmask16 = _kandn_mask16(m1, m2);   // NOT m1 AND m2
```

All widths (8/16/32/64) have corresponding variants. Convert with
`_cvtu64_mask64(u64)` / `_cvtmask64_u64(mask)`.

## Key Intrinsics

### Ternary Logic (`vpternlogd/q`) -- `avx512f`

Any boolean function of three vectors in one instruction. The 8-bit immediate
encodes a truth table over the 3 input bits at each position.

```rust
pub fn _mm512_ternarylogic_epi64(a: __m512i, b: __m512i, c: __m512i, const IMM8: i32) -> __m512i
```

| IMM8 | Operation | IMM8 | Operation |
|------|-----------|------|-----------|
| `0x80` | `a & b & c` | `0xFE` | `a \| b \| c` |
| `0x96` | `a ^ b ^ c` | `0xCA` | `(a & b) \| (!a & c)` (MUX) |
| `0xF0` | `a` (pass) | `0x0F` | `!a` |
| `0xFC` | `a \| b` | `0x3C` | `a ^ b` |
| `0xE8` | majority | `0x00`/`0xFF` | zero / all-ones |

Replaces 2-3 instruction sequences. Masked variants: `_mm512_mask_ternarylogic_epi64`.

### Compress / Expand

Compress packs active elements contiguously. Core building block for branchless filtering.

```rust
// 8-bit compress -- avx512vbmi2
pub fn _mm512_mask_compress_epi8(src: __m512i, k: __mmask64, a: __m512i) -> __m512i
pub unsafe fn _mm512_mask_compressstoreu_epi8(addr: *mut i8, k: __mmask64, a: __m512i)

// 32-bit compress/expand -- avx512f
pub fn _mm512_mask_compress_epi32(src: __m512i, k: __mmask16, a: __m512i) -> __m512i
pub fn _mm512_mask_expand_epi32(src: __m512i, k: __mmask16, a: __m512i) -> __m512i
```

```
Input:  [A, B, C, D, E, F, G, H]   Mask: 1 0 1 0 0 1 0 1
Output: [A, C, F, H, 0, 0, 0, 0]   (maskz variant)
```

### Permute (Cross-Lane Shuffle)

Full cross-lane permutation, overcoming AVX2 lane boundaries.

```rust
// Byte permute (each idx byte selects source byte 0..63) -- avx512vbmi
pub fn _mm512_permutexvar_epi8(idx: __m512i, a: __m512i) -> __m512i
// Two-source byte permute (idx selects from 128-byte concat) -- avx512vbmi
pub fn _mm512_permutex2var_epi8(a: __m512i, idx: __m512i, b: __m512i) -> __m512i
// 32-bit element permute -- avx512f
pub fn _mm512_permutexvar_epi32(idx: __m512i, a: __m512i) -> __m512i
```

### Conflict Detection -- `avx512cd`

Detects duplicate values within a vector for safe scatter operations.

```rust
pub fn _mm512_conflict_epi32(a: __m512i) -> __m512i
```

For position `i`, result is a bitmask of prior positions `j < i` where
`a[j] == a[i]`. All-zero = no conflicts, scatter is safe.

### Compare to Mask

Comparisons write directly to mask registers (not -1/0 vectors like SSE/AVX2).

```rust
pub fn _mm512_cmpeq_epi8_mask(a: __m512i, b: __m512i) -> __mmask64     // avx512bw
pub fn _mm512_cmpgt_epi8_mask(a: __m512i, b: __m512i) -> __mmask64     // avx512bw
pub fn _mm512_cmpeq_epi32_mask(a: __m512i, b: __m512i) -> __mmask16    // avx512f
pub fn _mm512_mask_cmpeq_epi8_mask(k: __mmask64, a: __m512i, b: __m512i) -> __mmask64
```

## VL (Vector Length) Variants

VL (`avx512vl`) makes AVX-512 features available at 128/256-bit widths.

**Why it matters**: (1) avoids frequency throttling on older Intel while gaining
masking and new ops, (2) better for small data, (3) interops with AVX2,
(4) ternary logic, compress/expand, compare-to-mask at 128/256-bit.

```rust
// 256-bit masked compare -- avx512bw + avx512vl
pub fn _mm256_cmpeq_epi8_mask(a: __m256i, b: __m256i) -> __mmask32
// 256-bit ternary logic -- avx512f + avx512vl
pub fn _mm256_ternarylogic_epi64(a: __m256i, b: __m256i, c: __m256i, const IMM8: i32) -> __m256i
// 256-bit compress -- avx512f + avx512vl
pub fn _mm256_mask_compress_epi32(src: __m256i, k: __mmask8, a: __m256i) -> __m256i
```

**Required features**: always `avx512vl` + the base extension for element width
(e.g., `avx512bw+avx512vl` for byte ops, `avx512vbmi2+avx512vl` for byte
compress/expand).

## Frequency Throttling

**The most important practical consideration for AVX-512 deployment.**

### Intel License Levels

| License | Trigger | Frequency Drop |
|---------|---------|----------------|
| **L0** | Scalar, SSE, 128-bit AVX | None (base turbo) |
| **L1** | 256-bit heavy (FP mul, FMA); 512-bit light (int, logic, shuffle) | Moderate |
| **L2** | 512-bit heavy (FP mul, FMA, some int mul) | Severe |

**Light ops** (lower license): int add/sub, AND/OR/XOR, shuffles, compares,
data movement. **Heavy ops** (higher license): FP multiply, FP add, FMA, int
multiply.

**Transitions**: upward ~20 us with brief stall; downward ~680 us relaxation.
Even one 512-bit heavy instruction holds L2 for ~680 us.

### By Microarchitecture

**Skylake-X / Cascade Lake (2017-2019)** -- Severe. 25% all-core frequency drop
at L2. Server Xeon Platinum: up to 30-35%. The 680 us relaxation window causes
constant oscillation with interleaved scalar code. HT siblings affected.

**Ice Lake / Tiger Lake (2019-2020)** -- Dramatically improved. ~100 MHz
reduction measured, often none at all. 256-bit stays at L0 unconditionally.

**Rocket Lake (2021)** -- No measurable throttling. i9-11900K held 5.1 GHz
regardless of instruction type.

**Sapphire Rapids (2023)** -- 256-bit execution units internally. 512-bit ops
crack into two 256-bit uops. Avoids heavy frequency penalties but throughput
per-instruction is halved. Small AVX-512 offset remains on paper.

**Alder Lake / Raptor Lake (2021-2023)** -- AVX-512 fused off. E-cores lack
support. Cannot use AVX-512 on desktop Intel 2021-2024.

**AMD Zen 4 (2022) / Zen 5 (2024)** -- **No frequency throttling at all.** Full
boost clocks maintained. 512-bit ops execute as two 256-bit uops internally
(double-pumped through 256-bit units). Throughput is half of 256-bit but
consistent and predictable. Zen 5 widens some paths for better 512-bit
throughput.

### Decision Matrix

| Scenario | Recommendation |
|----------|---------------|
| AMD Zen 4/5 | 512-bit freely; no throttling |
| Intel Skylake-X / Cascade Lake | 512-bit only in sustained hot loops |
| Intel Ice Lake / Rocket Lake | 512-bit, essentially free |
| Intel Sapphire Rapids | 512-bit fine; modest throughput gain |
| Alder Lake / Raptor Lake | No AVX-512; fall back to AVX2 |
| Mixed fleet (cloud) | 256-bit + VL features |
| Short bursts mixed with scalar | 256-bit + VL |

**General rule**: default to 256-bit + VL for mixed Intel fleets. Only opt into
512-bit when benchmarks prove a win. On AMD or Ice Lake+, use 512-bit freely.

## Runtime Detection Pattern

```rust
use std::arch::x86_64::*;

fn dispatch(data: &[u8]) -> usize {
    if is_x86_feature_detected!("avx512bw") && is_x86_feature_detected!("avx512vbmi2") {
        unsafe { process_avx512(data) }
    } else if is_x86_feature_detected!("avx2") {
        unsafe { process_avx2(data) }
    } else {
        process_scalar(data)
    }
}

#[target_feature(enable = "avx512bw,avx512vbmi2")]
unsafe fn process_avx512(data: &[u8]) -> usize { todo!() }

#[target_feature(enable = "avx2")]
unsafe fn process_avx2(data: &[u8]) -> usize { todo!() }

fn process_scalar(data: &[u8]) -> usize { todo!() } // SSE2 baseline on x86-64
```

**Bundle detection**:

```rust
fn has_avx512_skylakex() -> bool {
    is_x86_feature_detected!("avx512f") && is_x86_feature_detected!("avx512bw")
        && is_x86_feature_detected!("avx512cd") && is_x86_feature_detected!("avx512dq")
        && is_x86_feature_detected!("avx512vl")
}

fn has_avx512_icelake() -> bool {
    has_avx512_skylakex()
        && is_x86_feature_detected!("avx512vbmi") && is_x86_feature_detected!("avx512vbmi2")
        && is_x86_feature_detected!("avx512vnni") && is_x86_feature_detected!("avx512bitalg")
        && is_x86_feature_detected!("avx512ifma") && is_x86_feature_detected!("avx512vpopcntdq")
}
```

**Compile-time** (binary won't run on older CPUs):
```bash
RUSTFLAGS="-C target-cpu=icelake-server" cargo build --release
RUSTFLAGS="-C target-cpu=znver4" cargo build --release        # AMD Zen 4
RUSTFLAGS="-C target-feature=+avx512f,+avx512bw,+avx512vl" cargo build --release
```

## Code Example: Masked Byte Filter with Compress-Store

Remove `\n`/`\r` from a buffer using compare-to-mask + compress-store.

```rust
#[cfg(target_arch = "x86_64")]
use std::arch::x86_64::*;

#[cfg(target_arch = "x86_64")]
#[target_feature(enable = "avx512bw,avx512vbmi2")]
unsafe fn filter_newlines_avx512(src: &[u8], dst: &mut [u8]) -> usize {
    let (len, mut si, mut di) = (src.len(), 0usize, 0usize);
    let nl = _mm512_set1_epi8(b'\n' as i8);
    let cr = _mm512_set1_epi8(b'\r' as i8);

    while si + 64 <= len {
        let chunk = _mm512_loadu_si512(src.as_ptr().add(si) as *const i32);
        let is_eol = _kor_mask64(
            _mm512_cmpeq_epi8_mask(chunk, nl),
            _mm512_cmpeq_epi8_mask(chunk, cr),
        );
        let keep = _knot_mask64(is_eol);
        _mm512_mask_compressstoreu_epi8(dst.as_mut_ptr().add(di) as *mut i8, keep, chunk);
        di += keep.count_ones() as usize;
        si += 64;
    }

    if si < len {
        let tail_mask: __mmask64 = (1u64 << (len - si)) - 1;
        let chunk = _mm512_maskz_loadu_epi8(tail_mask, src.as_ptr().add(si) as *const i8);
        let is_eol = _kor_mask64(
            _mm512_mask_cmpeq_epi8_mask(tail_mask, chunk, nl),
            _mm512_mask_cmpeq_epi8_mask(tail_mask, chunk, cr),
        );
        let keep = _kandn_mask64(is_eol, tail_mask);
        _mm512_mask_compressstoreu_epi8(dst.as_mut_ptr().add(di) as *mut i8, keep, chunk);
        di += keep.count_ones() as usize;
    }
    di
}

pub fn filter_newlines(src: &[u8], dst: &mut [u8]) -> usize {
    assert!(dst.len() >= src.len());
    #[cfg(target_arch = "x86_64")]
    if is_x86_feature_detected!("avx512bw") && is_x86_feature_detected!("avx512vbmi2") {
        return unsafe { filter_newlines_avx512(src, dst) };
    }
    let mut di = 0;
    for &b in src { if b != b'\n' && b != b'\r' { dst[di] = b; di += 1; } }
    di
}
```

**Key techniques**: `_mm512_cmpeq_epi8_mask` (64-byte compare to mask),
`_kor_mask64`/`_knot_mask64`/`_kandn_mask64` (mask arithmetic on k-regs),
`_mm512_mask_compressstoreu_epi8` (branchless pack to memory),
`_mm512_maskz_loadu_epi8` (safe tail handling without overread),
`count_ones()` (popcount on mask for pointer advance).
